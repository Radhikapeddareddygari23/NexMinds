Module 1: Advanced SQL for Analysts

  • Complex Joins & Subqueries
  • Window Functions (RANK, LEAD, LAG)
  • CTE (Common Table Expressions)
  • Data Aggregation & Grouping

Module 2: Python Data Wrangling

  • Pandas DataFrames Manipulation
  • Handling Missing Data & Outliers
  • Time-Series Data Analysis
  • Automating Data Transformation Pipelines

Module 3: Business Intelligence with Power BI

  • Data Modeling & Star Schemas
  • Calculated Columns & DAX Measures
  • Interactive Visualizations & Slicers
  • Publishing & Sharing Power BI Reports

Module 4: Predictive Data Modeling

  • Correlation & Regression Analysis
  • Customer Segmentation (K-Means Clustering)
  • A/B Testing & Statistical Tests
  • Executive Business Reporting

8. Practical Activities & Projects

Every participant completes graded sprint tasks and a final capstone project:

  • Sprint 1: Query and analyze a multi-table relational sales database using advanced SQL window functions.
  • Sprint 2: Perform comprehensive Exploratory Data Analysis (EDA) on a 100,000+ row dataset using Pandas and Seaborn.
  • Sprint 3: Build an enterprise-grade interactive Business Intelligence Dashboard in Power BI with KPI cards and drill-through filters.
  • Capstone: Deliver a complete Customer Segmentation & Lifetime Value predictive analysis report with business recommendations.
