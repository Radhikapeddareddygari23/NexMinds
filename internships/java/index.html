8. Practical Activities & Projects

Every participant completes graded sprint tasks and a final capstone project:

  • Sprint 1: Develop an in-memory banking transaction ledger using Java OOP and Collections.
  • Sprint 2: Build a production REST API for an Employee Management System using Spring Boot & MySQL.
  • Sprint 3: Implement JWT authentication, role-based authorization, and secure endpoints.
  • Capstone: Deliver a full-scale E-Commerce Order & Inventory Microservice with unit test coverage.
